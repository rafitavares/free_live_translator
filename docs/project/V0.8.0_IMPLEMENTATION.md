# Church Cap v0.8.0 Implementation Status

Last updated: 2026-08-25

Status: updater trust was rotated before publication on 2026-08-25; the replacement Apple Silicon and unsigned Windows x64 releases are complete, the desktop updater artifacts independently verify against public key `BF1E020A4490108A`, and the project owner has confirmed the final Mac and Windows applications work correctly. GitHub source synchronisation, release publication, and post-publication updater manifests remain.

Church Cap v0.8.0 starts from the v0.7.6 source baseline. v0.7.4 remains the completed security/hardening baseline. The release objective is a native Windows x64 setup executable, a signed and notarized Apple Silicon DMG, and a curated Linux CLI archive, while retaining the existing browser-first product. The user accepted deferring Windows Authenticode for v0.8.0; the Windows release must therefore remain explicitly labelled unsigned and checksum-verifiable rather than being described as signed.

The maintained design and release references are [CROSS_PLATFORM_ARCHITECTURE.md](CROSS_PLATFORM_ARCHITECTURE.md) and [DESKTOP_UPDATE_RELEASE_RUNBOOK.md](DESKTOP_UPDATE_RELEASE_RUNBOOK.md).
