# Church Cap v0.7.6 Acceptance Test Framework

Use this framework to decide whether v0.7.6 is ready for a live service. Run update and password-throttle tests on a test installation or disposable appliance, not immediately before a service. The first deterministic Service Context implementation is available for testing but remains outside the release baseline until its remaining corpus, privacy, resource and multi-platform gates pass.

## Release Gate

v0.7.6 is ready for the tested production system only when:

- every applicable P0 task passes
- no unresolved failure can stop audio capture, captions, login, blanking, or audience delivery
- Room Display and OBS pass on their real output dimensions
- every translation language intended for the service passes a live test
- every translated-audio language intended for the service passes native-listener, headphone, privacy and target-hardware tests
- the target system completes the endurance test without uncontrolled storage or memory growth
- the service report and notes are retained for comparison, without sharing private caption content
