# Church Cap v0.8.0 dependency audit

Audit date: 24 August 2026

Tooling: `pip-audit` 2.10.1 against `requirements-packaged.txt`, plus Bandit 1.9.4 high-severity scanning of the application, engine, desktop source, and scripts.

## Result

Bandit reported no high-severity source finding. `pip-audit` reported five distinct upstream advisory IDs across two installed packages (one Transformers ID was emitted twice by the advisory data).

| Package | Pinned/resolved version | Advisory | Church Cap reachability decision |
|---|---:|---|---|
| Transformers | 4.57.6 | `PYSEC-2025-217` | Affects X-CLIP checkpoint conversion. Church Cap does not invoke X-CLIP. |
| Transformers | 4.57.6 | `PYSEC-2026-2288` | Affects the Trainer checkpoint RNG-state loader. Church Cap does not invoke Trainer. |
| Transformers | 4.57.6 | `PYSEC-2026-2289` | Affects `AutoModelForCausalLM`. Church Cap uses pinned SMaLL-100 `M2M100ForConditionalGeneration` and local/pinned tokenizers, not causal-language-model loading. |
| Transformers | 4.57.6 | `PYSEC-2026-2290` | Affects LightGlue nested model loading. Church Cap does not invoke LightGlue. |
| Stanza | 1.10.1, transitively pinned by Argos Translate 1.11.0 | `PYSEC-2026-3075` | Affects unsafe Stanza model deserialization. Church Cap forces `ARGOS_STANZA_AVAILABLE=0` and `ARGOS_CHUNK_TYPE=MINISBD` before Argos use and does not load a Stanza pipeline/model. |

## Release handling

CI contains exact advisory-ID exceptions for these five findings so unrelated or newly discovered dependency findings still fail the build. The exceptions are a narrow reachability decision, not a claim that the upstream packages themselves are fixed.

Transformers fixes require a major-version upgrade (at least 5.3/5.5 for the relevant model-loading advisories), while the v0.8.0 translation installers and CTranslate2 conversion path currently target Transformers 4.x. Argos Translate 1.11.0 is the latest release and pins Stanza 1.10.1 exactly. Blindly overriding either dependency would make the committed source differ from the already-built Mac and Windows candidates and could break translation.

For v0.8.0:

- retain pinned model revisions, SHA-256 validation of the custom SMaLL-100 tokenizer, `use_safetensors=True`, `trust_remote_code=False`, local-only Tigrinya runtime loading, and Argos archive validation;
- do not add generic/user-selected Hugging Face model loading or expose the affected model classes;
- disclose the exceptions in this document and keep CI exceptions tied to exact advisory IDs;
- treat any future use of Trainer, X-CLIP, causal LM, LightGlue, Stanza models, or unpinned remote model repositories as release-blocking.

For the next dependency refresh, test Transformers 5.5 or newer across SMaLL-100, Tigrinya, and CTranslate2 conversion, and replace/fork Argos or remove the unused Stanza dependency when an upstream-compatible route exists. Rebuild and re-sign platform artifacts after that change.
