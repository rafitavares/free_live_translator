# Church Cap v0.8.0

**Making Church Easier to Follow.**

Church Cap v0.8.0 is the first cross-platform packaged release of the existing local-first, browser-first caption service. The Operator, audience, Room Display, OBS, translation, accessibility, privacy, and legal experiences still come from one shared web application. The native Mac and Windows applications start and supervise that local service; Linux remains a curated terminal-first package.

## Release validation

The final Mac and Windows release candidates were installed and functionally tested on their respective operating systems. The Mac app and DMG are Developer-ID signed, Apple-notarized, and stapled. Both desktop updater artifacts carry independently verified Tauri signatures, and the published SHA-256 files identify the exact tested downloads.

## Highlights

- Native Church Cap desktop management for Apple Silicon Mac and Windows x64, with a menu-bar or system-tray presence and a centred control window.
- Automatic local-server startup, health monitoring, safe stop/restart/quit behaviour, browser shortcuts, and protection against orphaned background servers.
- Browser-first operation: visitors still scan a QR code and read captions without installing an application.
- Opt-in start at login and opt-in update checks. Updates are never installed without operator approval.
- Signed desktop update architecture with platform-specific manifests, mandatory Tauri verification, live-caption protection, and failed-install recovery.
- Native password and security-mode recovery without Terminal on Mac or Windows.
- Clear Secure Operator and Easy Offline security-mode guidance during first setup and recovery.
- Packaged translation, spoken-language model, and Windows CUDA installation paths with visible progress and safe CPU fallback.
- Church Cap-styled installers, application icons, native controls, system light/dark appearance, and offline legal information.
- A curated Linux archive with package-manager detection, optional local CUDA support, and project-local Python 3.12 fallback on distributions whose system Python is too new.

## Important notes

- The Mac application supports Apple Silicon. Intel Mac is not included in v0.8.0.
- The Windows installer is currently unsigned by Authenticode, so Windows may show SmartScreen. Verify the published SHA-256 before continuing.
- Linux remains terminal-first rather than providing a tray application, AppImage, DEB, RPM, Flatpak, or Snap.
- Model, translation, spoken-language, and optional CUDA downloads require internet access and can use substantial disk space.
- AI-generated captions can be inaccurate. Test the exact computer, model, microphone or sound-desk route, network, displays, and languages before a live service.

Church Cap is free and open source under the MIT License. Caption audio and normal application data remain local unless an operator explicitly exports or shares something.
